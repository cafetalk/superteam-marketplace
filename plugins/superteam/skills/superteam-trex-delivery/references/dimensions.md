# 部署变更维度参考

提测单 / 发布文档里「受影响系统 / 部署变更」矩阵的 20 个 canonical 维度。
顺序与钉钉历史一致；`key` 为中文短名，是模板与记录里的稳定标识。
**只填本次该系统实际涉及的维度**，未涉及的留空（渲染时不出现）。

每个维度填两列：`beta`（预发环境要做什么）/ `prod`（生产环境要做什么，常写「同 beta」）；
再加「操作人」和「检查」（☐/☑）。

| 维度 key | 说明 | 填写要点 |
|---|---|---|
| MSE配置 | Nacos/MSE 配置新增或修改 | 写清新增/改动的 dataId、group，及配置值要点 |
| RDS DDL | 表结构变更 | 建表 / 加字段 / 改索引的 DDL 脚本或文件名 |
| RDS DML | 数据修订脚本 | 数据初始化 / 修订 SQL，注明影响行数与可重入性 |
| TableStore表 | OTS 表变更 | 新建 / 调整的 OTS 表名与主键设计 |
| TableStore索引 | OTS 索引变更 | 新建 / 调整的二级索引或多元索引 |
| Redis | Redis key / 实例变更 | 新增 key 前缀、TTL、是否需要新实例 |
| 其他云服务 | OSS/SLS/函数等 | 涉及的 OSS bucket / SLS logstore / 函数计算等改动 |
| 容器镜像 | 镜像构建/部署后置操作 | 镜像 tag、部署后置脚本、需要的滚动顺序 |
| 机器配置 | 机器规格/数量 | 实例规格、副本数变化 |
| JVM版本 | JDK 版本 | 目标 JDK 版本及升级注意点 |
| JVM参数 | 启动参数/堆栈 | -Xmx / GC / 其他启动参数调整 |
| 监控配置 | 告警/监控项 | 新增/调整的监控项与告警阈值 |
| 日志采集配置 | 日志采集 | 日志路径 / 采集规则变更 |
| 内部LB | 内部 LB 端口/地址 | 内部负载均衡端口、后端地址变更 |
| 外部LB | 外部 LB 端口/地址 | 对外暴露端口、域名、证书变更 |
| K8s组件变更 | k8s 组件 | Deployment/Service/ConfigMap 等 k8s 资源改动 |
| 调度任务 | 定时/调度任务 | 新增/调整的定时任务、cron 表达式 |
| MQ配置 | MQ topic/消费组 | 新增 topic、消费组、消息体兼容性 |
| RPC兼容性 | Dubbo/Grpc 接口兼容性 | 接口签名变更是否向后兼容，是否需要灰度顺序 |
| 服务器脚本 | 服务器终端脚本 | 需要在服务器终端手工执行的脚本及执行人 |

> 维度清单的权威来源是 `scripts/dimensions.py` 的 `DIMENSIONS`；改维度时同步改这两处。
